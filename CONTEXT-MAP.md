# Context Map

## Contexts

- [Sprite Project](./CONTEXT.md) — project-wide product vocabulary: the
  products, their boundaries, and the pane-first identity
- [Terminal Core](./phase_1/CONTEXT.md) — Sprite Terminal's internal
  vocabulary: sessions, panes, snapshots, observation

## Relationships

- **Sprite Project → Terminal Core**: "Sprite Terminal" in the project
  context is the product whose internals the Terminal Core context describes.
- **Terminal Core's "Croft Compatibility Gate"** refers to what the project
  context calls "Croft (upstream)" in its acceptance-application role.
- Phase_1 documents predate the multi-product vocabulary and use "Sprite" to
  mean Sprite Terminal; they are grandfathered, not errors.
